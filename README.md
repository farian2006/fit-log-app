Project Name : Fit Log App

Description : 
Fit Log is a workout planning app designed to help users to organize and manage their fiteness
Here users can explore different excercise, view detailed info and create their personalized workout plans


Technologies : 
1. Next.js
2. React
3. TypeScript
4. Tailwind CSS
5. React Toastify
6. React Icons
7. daisyUI

Key Features : 
1. Browse & explore different excercises
2. View detailed excercise information
3. Create and manage workout plans
4. Save excercise for later
5. Responsive interface
